# Gender Discrimination Detection

Тестова система на основі методу нейромережевої ідентифікації гендерної дискримінації у соціальних медіа за мультимодальними даними (текст, аудіо, відео).

## Скорочення датасетів

| Скорочення | Повна назва | Опис |
|---|---|---|
| **SSMB** | Sexism Social Media Balanced | Збалансований датасет з публікацій у соціальних медіа. 20 108 записів, розподіл класів 50/50. |
| **SDET** | Sexism Detection English Text | Датасет для виявлення сексизму в англомовних текстах. 20 000 записів (train/dev/test), незбалансований (76% / 24%). |

## Моделі

| Модель | Датасет | Precision (S) | Recall (S) | Macro F1 | Accuracy |
|---|---|---|---|---|---|
| BiLSTM | SSMB | 0.83 | 0.79 | 0.82 | 82% |
| BiLSTM | SDET | 0.53 | 0.69 | 0.72 | 78% |
| RoBERTa | SSMB | 0.87 | 0.86 | 0.87 | 87% |
| RoBERTa | SDET | 0.67 | 0.80 | 0.81 | 85% |
| RoBERTa | SDET (augmented) | 0.67 | 0.80 | 0.82 | 86% |

*(S) — метрики для класу Sexist*

## ⚠️ Примітка щодо моделей

Через жорсткі ліміти GitHub на розмір файлів (максимум 100 МБ на файл) навчені ваги моделей (зокрема файли `.safetensors` для RoBERTa, які важать близько 500 МБ) **не включені** у цей репозиторій. 

Щоб запустити систему локально, вам необхідно самостійно натренувати моделі. Для цього:

1. Завантажте оригінальні датасети у папку `datasets/` згідно зі структурою.
2. Відкрийте потрібний блокнот з папки `notebooks/` у Google Colab (або локальному Jupyter).
3. Виконайте навчання. Скрипт автоматично згенерує `.zip` архів з навченою моделлю.
4. Розпакуйте вміст архіву у відповідну підпапку в `models/`.

Після цього система автоматично підтягне навчені моделі.

## Можливості системи

**Режим Text** - аналіз тексту довільної довжини. Для текстів з кількох речень застосовується алгоритм ковзного вікна, який виявляє сексистські фрагменти навіть якщо вони займають невелику частину загального тексту.

**Режим Audio** - завантаження аудіофайлу (WAV, MP3, M4A, OGG), транскрибація через OpenAI Whisper, класифікація.

**Режим Video** - за допомогою бібліотеки `moviepy` з відео (MP4, MOV, AVI, MKV) витягується аудіодоріжка, після чого відбувається її транскрибація і класифікація.

Вибір між 5 моделями доступний прямо в інтерфейсі.

## Алгоритм ковзного вікна

Вхідний текст розбивається на речення. Далі вікно розміром `window_size` речень проходить по тексту з кроком `stride`.

Фінальна оцінка:

```
final_score = 0.6 * P90(window_scores) + 0.4 * (max_score * isolation_penalty)
```

Коефіцієнт `isolation_penalty` знижує оцінку, якщо сексистські речення поодинокі серед нейтрального тексту (ймовірний контекстуальний сексизм, а не системний).

## Навчання моделей

Файли в папці `notebooks/` адаптовані для Google Colab. Кожен формує ZIP-архів з результатами (модель, токенізатор, метрики, графіки, хмари слів).

## Захист від перенавчання

- `EarlyStopping` за `val_loss` / `val_f1` (patience 3-5)
- `Dropout` шари в BiLSTM
- `weight_decay=0.01` + `AdamW` для RoBERTa
- `class_weight` для SDET (незбалансований датасет)
